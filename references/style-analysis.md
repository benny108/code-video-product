# 风格提取与动态分镜

## 证据先于标签

以实际指南、媒体和上游版本为依据。只读被选中的风格；需要比较时再读相邻风格。参考等级分别记录：

1. 可编辑原场景代码：可直接运行核对真正时间线。
2. 原作者完整视频：可测量全片；不说明有源码。
3. GIF / 静帧 + 指南：只能证明所见片段和视觉语法；补全部分是重建。
4. 自己做过的复现：可借鉴技术与退修，不代替原作者参考。

GIF查看连续帧，完整片跨章节取代表帧；关键转场从真实发生时段取样。媒体查看服从当前工具限制，不为绕过展示限制擅自下载。

## STYLE-SPEC.md 建议内容

按任务裁剪，不强制镜头数量：

```text
目标：模式 / 主题 / 时长 / 规格 / 原稿替换范围
参考：版本 / 文件或URL / SHA / 是完整片还是短片段
主体：角色轮廓、造型细节、道具组合、主次关系
空间：主体bbox÷画幅、字号÷画高、地平线/面板位置、留白
材质：像素网格/描边/纸纹/网点/阴影/发光的可观察特征
字体：标题/说明/数字/手写注/元信息的角色、字形与许可
色彩：背景、主墨色、强调色分别用于什么
动作：起点→接触或变化→结果；锚点、父子变换、遮挡
镜头：固定/横移/缩放；世界坐标与屏幕HUD分开
转场/收尾：机制、跨页状态、淡出或持帧、最终帧
声音：是否静音/无旁白；事件、音效、高潮落点
不变量：不可因内容替换而简化的风格特征
可替换项：用户授权的内容与道具
未知：没有参考覆盖或不能直接确认的部分
验收：风险时间窗、对照帧、具体通过条件
```

比例用参考原尺寸或归一化测量；含播放器边框的截图先限定视频区域。保留估计误差，不把单张截图占比当所有镜头的规定。动作会改变bbox，记录同类镜头范围。

## detective 核心不是“棕色卡片”

依据 `detective.md` 保留这些关系：

- 台灯照明的暖软木板、暗角；居中的灰未知人物卡、奶油色斜证据卡、黄/粉手写便笺。
- 红色统一用于图钉、**绷直并接到真实钉位**的线、勾画、纠正和印章。
- 连续巡查镜头依次揭证据，再拉远看网络；不是每张卡片一次硬切。
- 一次全幅闪光揭晓结果；结果保留到整体收尾，不淡出后露出旧问号。
- 圆润无衬线与手写注分工；编号/引用不丢失。印章、底栏、标题有间隔。
- tick/脉冲渐进，闪光处一次主高潮、尾音衰减；原例无旁白不强加 TTS。

新主题可将“未知产品”换成“为什么订单不赚钱”的案件，但证据和线须承载因果，非装饰。复现原例则保留原主题和可见数据，不借机创作新故事。

## handdrawn 与 rpg 不能共用方块人

**handdrawn**：暖白留白纸、细墨地平线/轮廓云，8-bit迷你角色实际推/砸/站上道具；深色衬线标题与像素关卡穿插。字体分工为衬线数字、手写注、像素分数、mono标签。用户要真人2D造型时属于授权改编，保留纸/墨/留白，明确与原像素例不同。

**rpg**：固定低分辨率背景、角色装备/轮廓、像素阴影字、钢灰斜面面板、槽条/奖励卡、CRT纹理、战斗/升级反馈。角色占比从原参考测量，不为“看得清”随意放大；高清矩形加scanline不等于像素美术。

## 分镜由事件推动

一条事件可记录：`时间窗、起因、角色/物体动作、信息变化、镜头、声音、理解停留、风险点`。

- 武器接触→闪光→敌人受力→经验/结果更新，不能先结算再挥剑。
- 原值→划掉→箭头→新值，笔尖到哪墨迹推进到哪。
- 漫画/绘本新页真实覆盖旧页，页影滑过同一静图再硬切不算翻页。
- 公式/柱增长有正确输入、计算和结果；自拟数字标为示例，真实数字注明来源及条件。

讲述可以自由，不知不觉降低美术不可以。动作丰富不意味着所有镜头都摇晃/放大/喷粒子；原例固定镜头须保持其固定镜头语法。
