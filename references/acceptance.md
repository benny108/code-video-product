# 验收与可编辑交付

技术可脚本化，美术/因果/自然讲述仍需看真实媒体。不要一个技术pass推导全部pass。

## 源码与核心段
- 原参考版本/核心特征有证据，出处分类正确。
- 原尺寸静帧查主体占比、字体层级、道具组合、材质、空隙；与参考同类镜头同尺度。
- 动作段含完整前因后果，不只剪漂亮静态停留。
- 接触/页转/旋转连接/fade从实际MP4取连续帧，慢播或连续表查看；六张均匀抽帧不是连续30fps。
- 有审查者时保存独立观察；没有就主控检查并诚实记，不杜撰peer pass。

## 最终编码
1. ffprobe获取实际分辨率、fps、duration、帧数、视频/音频流；`ffmpeg -v error -i <file> -f null -`完整解码。末帧index=N−1不是N。
2. 跨章节帧覆盖开场、每段、不同转场、收尾；另审风险连续窗口。
3. 高清查小字、来源行、印章/字幕间隙、裁切、细线/像素；核对原例辨识特征。
4. 音频流/时长/响度/削波属技术，试听语气/停顿/配乐/事件落点才是听审；静音pass不能报已听。
5. 核对算式、单位、结果、示例标记、真实来源。上游性能报告不冒称当前电脑实测；不造金句/真人证词。

## 独立工程包
审核前冻结输入ZIP字节及SHA，再从冻结包解压，不让作者边审边覆盖。

按任务提供源码/index/helper、锁定或可重建依赖、本地素材/字体/音频、来源/完整许可、动态分镜/说明。README写真实命令、目录、duration、视频是否另下；避免node_modules、私有参考声、凭据、本机绝对路径、重型重复QA。成片是否进ZIP按需求，链接不能指不存在的包内文件。

独立临时目录查CRC、依赖、路径、许可证/署名；加载字体，真渲染代表帧检查运行错误。helper针对当前固定参考做SHA对比，不把历史SHA当未来唯一标准。

## 发布与前端
仅到已授权目标；独立版本/内容哈希快照，审核结果绑定MP4/ZIP SHA，不覆盖已发布版本。
- HTTP正确内容/MIME，视频Range请求返回206。
- 下载字节SHA与冻结一致。
- 浏览器实播至ended，查正常速率/duration/decoded/droppedFrames/JS错误；掉帧如实记录。
- 前端查画风名/出处标记/下载链接/桌面与窄屏，不混官方片与复现片。

## 记录实际而非照抄通过
建议报告字段：`mode、style、参考依据、产物路径/SHA、技术结果、代表帧时间、连续窗口、HD位置、humanListening、packagePortable、browserPlayback、knownDifferences、decision`。

关键段/候选/已验成片分开。参考不足写不足，用户美术确认与已做技术/画面检查分别记录；不要复制他人报告的true字段冒充本次结果。
