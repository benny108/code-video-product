# 实际踩坑：定位、窄修、复验

仅对应症状时使用，不能把单个浏览器/任务现象变成所有视频强制补丁。

| 症状 | 先验证什么 | 最小修法与复验 |
|---|---|---|
| 名字对但画面不像 | 原参考比例、道具、材质、字体、核心动作，而非作者自写SPEC | 补美术基线，HD+核心运动短段，不只换颜色 |
| 短段跑出整片 | 新exec不继承cwd；真实HTML的VIDEO.dur/时间偏移 | 显式绝对workdir，preflight预期秒数；误产物标未审 |
| 成功却无末帧图片 | 末帧为(N−1)/fps，四舍五入可能越过片尾 | 按帧号抽真实MP4并查文件存在，不拿exit0当成功 |
| 末帧没淡黑 | 编码只到(N−1)/fps；fade结束更晚或子层重设alpha | 查末帧及连续段，整层fade；原持帧风格不强加黑 |
| 有音频后整片变短 | 原mux有-shortest，音频实际时长 | 音频尾音/静音补至视频时长，验最终帧数 |
| 字体loaded但字不对 | family与generic重名、weight范围、glyph fallback/中文覆盖 | 独特family/CSS范围/原尺寸字形对照；loaded不证明字形 |
| 父层淡了箭头仍亮 | 子helper重设alpha1或覆盖父值 | 子alpha乘继承值，save/restore；查关联物同淡出 |
| 收尾缩到左上角 | 低清缓存画进高清canvas时identity transform/缺目标尺寸 | 明确drawImage目标宽高，统一逻辑/物理尺寸 |
| 同帧重复render不同 | 未设种子/累积状态/异步资源/绘制顺序/clip cache | 先确定性检查；确证浏览器缓存才局部flush/预热，不默认双绘全片 |
| 手持/线/吊绳脱节 | 连接双方各自算不同坐标/transform | 公用真实锚点/矩阵，连续帧复查，不装饰遮断点 |
| 相机动人物原地踏步 | world是否真移动；camera是否算进主体/灯 | 世界动作/HUD分离，查接地/到位停步/过场 |
| 编码后cleanup错误 | 原renderer绝对输出可能重复拼root；parent是否存在 | 创建子目录，用工程内相对MP4路径；先解码查日志，不盲重跑 |
| ffmpeg目录不可执行 | 传目录而非binary；PATH/cwd丢失 | 显式可执行/PATH与workdir；本机路径不写交付包 |
| 反复返工同问题 | 修单仅聊天，或“精致些”无条件 | 落盘位置/缺陷/参考/验收，窄查修改与边界 |
| 小错整片重复编码 | 未先HD；文档和视频绑定重做 | 排版先静帧、动作先窄段；文档错只打包 |
| 制作慢 | 测捕获/编码/等审耗时和CPU内存，blur/workers影响 | 共用SHA证据，减少空等；短段质量/耗时对照调参，不降规格 |
| 换目录ZIP不运行 | 隐藏依赖、绝对路径、package/lock缺失 | 冻结ZIP独立解压、相对资源/可重建依赖/完整许可，真渲染 |
| 许可只是摘要 | 实际字体/图/代码要求的全文与署名 | 附真实许可/来源，免费TTS不等于可商用 |
| 待审文件被覆盖 | 初始与现在字节SHA | 冻结输入，修改新版本名，旧结论绑定旧SHA |
| 包文案是取消品牌 | 全包目标/链接/MP4包内存在性 | 修文档，不重视频；禁止词只针对当前任务 |
| 端口在链接打不开 | 真实HTTP/cwd被删/进程归属 | 固定directory/workdir，仅重启本任务服务，验Range/播放 |
| resize双标题截图 | DOM数量、字体ready、动画稳定 | fonts.ready+两次RAF或新viewport页，先排除截图伪影 |
| 虚报全帧/听审 | 实际看过多少独立帧/采样fps/有没有听 | 报真实覆盖，存全帧不是看全帧，静音播放不是听审 |

## 窄修记录

```text
候选：文件/版本/SHA；本次只修哪项
位置：局部与全片时间，或帧号
观察：具体缺陷及原参考依据
原因：已验证/待验证
修法：最小改动；不动哪些已通过部分
验收：连续窗口/HD位置/正确状态
结果：新候选SHA、实际覆盖、残留差异、是否准整片
```

同候选已发现阻塞一次列全，不每轮随意追加美术喜好。整片新开结尾/新场景须再验，不能从关键段pass推导全片pass。
